# Detailed environment — preview v0.6

The old cone trees, polyhedral stones and box crates/lamps now serve as immediate loading/error/low-quality fallbacks. Balanced and high modes automatically load bundled Poly Haven GLBs with real base-color, normal and roughness maps. Pine has three variants (about 30K triangles per visible tree); mossy rock has six. Crate and lantern have approximately 5K and 8K triangles. Only one model variant is attached per entity. Asset provenance and CC0 credits are in public/models/CREDITS.md.

Walls have staggered bevelled masonry and stone PBR surfaces; doors use wood PBR; platforms use stone; floors use paving or forest ground. UV density follows metres instead of stretching across each resized object. Standard/physical materials use a static room reflection environment, warm directional light and quality-scaled shadows. Humanoid markers have smoother clothing/anatomical forms and metal details; they are still generic miniatures, not finished character assets. Water and sound markers retain simple presentation.

Four model downloads total about 11.4 MB; the twelve shared surface maps total about 5.4 MB. Loading is on demand by kinds present. Model downloads are cached as bytes; parsed templates have reference-counted short leases across move/undo/rebuild to avoid reparsing on every command. Materials carrying clipping/remembered opacity are cloned per instance. Textures and geometry are released after the last lease; renderer-owned materials, poles, surfaces and reflection target are disposed on teardown. Idle rendering remains event-driven.

All variants are centred at the existing pivot and fitted within saved width/depth/height. Tall lamps combine the lantern with a post. No collision/support dimensions or server data formats change. Loaded models keep the same picking/dragging parent, selection outline, labels and pointer capture. Restricted views clone all material slots with disclosed-area clipping, and cast no shadows. No hidden-entity model list enters the renderer.

Validation: production TypeScript/Vite build; 14 existing affected editor/preview/3D UI tests; 3 real-GLTF asset tests covering checksums, embedded images/buffers, every available variant, finite geometry, saved bounds, PBR maps, shared geometry/private materials, late completion/disposal, UV density. Lint has pre-existing warnings outside these changes. Node asset tests stub ImageBitmap decoding and UI tests stub WebGLRenderer. A browser visual inspection and FPS measurement on RTX 2060 have not been performed; do not present these tests as GPU/visual verification.
