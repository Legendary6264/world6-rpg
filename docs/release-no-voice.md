# Грани Бытия — выпуск без встроенного голоса

13 октября 2026. Основание: завершённый этап `1b9d686` и решение пользователя завершить сайт без голоса. Рабочий голосовой прототип сохранён в прежней ветке; в этом выпуске нет его клиентских компонентов, микрофонных разрешений, WebRTC-сигнализации и TURN-настроек.

## Что доступно

- Регистрация и Supabase Auth, добровольный второй фактор игрока, обязательный второй фактор для привилегированных действий. Роли сайта отделены от ролей кампании.
- Лобби, приглашения, главный мастер, помощники с отдельными разрешениями, проверка героя и добровольная передача управления.
- Верхние и боковые сцены, свободные X/Y/Z, опоры, редактор мастера, индивидуальные раскрытия и знания героя.
- Приватные заявления, временная шкала, серверный расчёт и отдельное применение, движение, взаимодействия, способности, перенос подготовки и прерывания.
- NPC, населённые места, имущество, валюты, сделки и ручные правила периода учёта.
- Пауза, история, контрольные точки, полный архив, откат и переигровка. Старая команда не исполняется повторно после перезапуска.
- Текстовый чат людей в лобби. Реплики персонажей и журналы разговоров доступны только адресно по подтверждённой мастером слышимости; намерение подслушать само не раскрывает секреты.
- Изолированное обучение игрока и мастера, пример «Ночной переход», существующие тело, снаряжение, справочник и 3D.

## Первая игра

1. Войти в аккаунт. Если настроен второй фактор, подтвердить его в разделе «Аккаунт».
2. Мастеру создать лобби либо отдельную кампанию из примера «Ночной переход» и передать друзьям код приглашения.
3. Игрокам вступить, выбрать героя из облачных персонажей и добавить его в кампанию. Мастеру принять лист, разместить героя и раскрыть ему сцену.
4. Во вкладке «Раунд» мастер открывает сбор заявлений. Игроки составляют планы на собственных экранах; отправка плана не меняет мир.
5. Мастер закрывает сбор, подтверждает время/условия, рассчитывает последствия и отдельно применяет результат.
6. Перед перерывом поставить игру на паузу и создать контрольную точку. Полную резервную копию сохранять через инструменты кампании.

## Проверка и ограничения

Автоматические проверки покрывают правила, React DOM, настоящий HTTP/Socket.IO, SQLite/PostgreSQL, права, приватность и совместимость. Сквозной сценарий использует мастера и два независимых аккаунта игроков: вступление, рассмотрение героев, индивидуальную сцену, два заявления, расчёт/применение, паузу, контрольную точку, перезапуск и продолжение.

Ожидания тестов HTTP/UI привязаны к доступности кнопок после загрузки состояния. Временно заблокированная кнопка не обходится. Повторные проверки выполняются после этих исправлений.

Настоящий облачный вход с пользовательским паролем/TOTP, доставка писем и физический телефон не подменяются локальными тестовыми аккаунтами. Проверка без такого входа подтверждает доступность сайта/API и открытых интерфейсов, а не вход конкретного пользователя.

Расчёт темпа из характеристик, автоматическое восприятие и акустика не получили новых придуманных формул. В соответствующих местах используются явные решения мастера. Существующий адрес GitHub Pages и API сохранены; новая платная инфраструктура не добавляется.

Миграции приложения добавляют совместимые таблицы при запуске API и сохраняют существующие аккаунты. Доступ к приватной схеме `world6` остаётся через API; RLS и запрет публичного доступа сохраняются.
