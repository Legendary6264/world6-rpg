# Как сыграть с другом от начала до конца

Нужны два аккаунта: один человек ведёт игру как мастер, второй играет героем. Можно пригласить больше игроков. Мастер управляет историей, проверяет героев и принимает решения о последствиях.

## Запуск рабочей версии

Установи Node.js 24.x, распакуй исходники и открой терминал в папке с `package.json`:

```sh
npm ci
npm run dev:all
```

Открой адрес Vite, который появился в терминале, обычно `http://localhost:5173/`. Сервер и сайт запускаются одной командой. Не закрывай терминал до окончания игры. Для остановки нажми Ctrl+C. Локальные аккаунты и кампания сохраняются в `server/data/world6.sqlite`; при следующем запуске используй ту же папку.

Для двух устройств в одной частной сети вместо `dev:all` запусти:

```sh
npm run dev:lan
```

Передай другу адрес «Адрес для второго устройства» из терминала. Оба устройства должны находиться в одной сети. Если Windows спросит разрешение для Node.js, выбери доступ в своей частной сети. Режим использует сайт на порту 5173; API обслуживается через него. Если порт занят, запуск сообщит об этом.

Если адрес не определился, посмотри частный IPv4 своего компьютера через `ipconfig`. Например, для `192.168.1.10` в PowerShell:

```powershell
$env:LAN_HOST = "192.168.1.10"
npm run dev:lan
```

Укажи свой действительный адрес. Это запуск в локальной сети. Для участников из разных сетей нужны опубликованные сайт и API с постоянной базой и обычной регистрацией. Рабочие исходники включают новые функции; адрес ранее опубликованного сайта может обслуживать более раннюю версию.

## Создание и вход

1. Зарегистрируйся и открой «Лобби». Создай отдельную кампанию «Ночной переход», чтобы получить сцены, NPC и материалы, либо создай свою кампанию.
2. В «Подготовка» скопируй приглашение. Если браузер не разрешает автоматическое копирование, выдели поле «Ссылка приглашения» и скопируй его вручную. Можно передать код приглашения.
3. Друг открывает ссылку, входит под своим аккаунтом и нажимает «Вступить по приглашению». Перед началом игры пригласи всех участников: старт закрывает набор.
4. Игрок выбирает «Герои». Если сохранённого героя нет, кнопка «Создать первого героя» откроет редактор. Создай и сохрани героя, нажми «Вернуться в кампанию», выбери его в списке и отправь мастеру.
5. Мастер открывает заявку и принимает героя. Игрок увидит изменение статуса. Проверка мастера сохраняет условия конкретной кампании.

## Начало приключения

Во вкладке «Играть» мастер нажимает «Начать игру на сцене», выбирает сцену и принятых героев, точку входа, объекты и известных существ. В поле описания пишет то, что видят герои. Подтверждение раскрытия и кнопка «Разместить героев и открыть сцену» открывают выбранные сведения игрокам. Скрытые NPC и предметы не становятся видимыми автоматически.

В блоке «Совместная игра» отметятся вошедший участник, принятый герой и открытая ему сцена. Нажми «Начать совместную игру». Затем «Открыть раунд»: выбери сцену, участников и длительность, нажми «Начать приём заявлений».

## Игровой цикл

Игрок открывает «Играть» → экран своего героя. Нажатие на землю выбирает точку, «Идти к отметке» добавляет движение в ход. На известном предмете доступны осмотр, действия с дверью или контейнером; также есть речь, ожидание, предметы и утверждённые способности. Действия можно объединять в очередь, менять порядок и убирать. «Отправить заявление» отправляет план мастеру; само составление плана не меняет мир.

Мастер видит, сколько планов получено. Он закрывает приём, проверяет бюджеты, длительности, необходимые решения и подтверждения. Сначала нажимает «Рассчитать последствия раунда» и просматривает результат, затем «Применить рассчитанный раунд». Только применение меняет мир и игровое время. Стоимости и решения задаёт мастер по правилам вашей игры.

Игроки проверяют новую позицию, доступное состояние сцены, ощущения и журнал. Если действие не успело закончиться, мастер решает, продолжить или прервать его в следующем раунде. «Начать следующий раунд» сохраняет состав, сцену и длительность; каждый новый план снова отправляется отдельно.

Для первой короткой проверки достаточно движения одного героя, открытия известной двери и ожидания другого. После применения убедитесь, что оба игрока получили свои результаты.

## Перерыв и окончание

«Перерыв и продолжение» на игровом столе позволяет поставить игру на паузу с причиной и продолжить её позже. Пауза сохраняет позиции, заявления и текущую работу. Разрыв связи и обновление страницы не требуют создавать новую кампанию: вернись в то же лобби под тем же аккаунтом.

Когда история закончена, мастер нажимает «Завершить игру», пишет название и общий итог, проверяет его и нажимает «Сохранить итог и завершить». Итог увидят все участники. Одновременно сохраняется финальная контрольная точка и закрывается лобби. Время, ресурсы и знания не пересчитываются.

Если текущий сбор ещё не разрешён, сначала примени раунд или явно сохрани сбор в истории без исполнения. Незавершённые действия и заряды можно сохранить в финальном снимке отдельной отметкой; это не исполняет и не отменяет их. При заполненном хранилище контрольных точек сначала освободи место через «Копии и история»: завершение не удаляет прежние снимки.

После завершения игроки могут читать итог, сцену и свой журнал. Новые ходы и изменения знаний закрыты. Мастер может скачать полную копию в «Копии и история». Если ответ сохранения потерян, повтори ту же команду кнопкой «Повторить сохранение итога» — второй финал и второй снимок не создадутся.
