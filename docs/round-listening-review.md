# R08 · намерение прислушаться/подслушать

Продолжение после `a588067`. Использованы готовые заявления, точный исполнитель и адресная речь R08. Код не меняет канон, формулы слуха, XYZ/свободное движение или 3D; архитектурный аудит заново не проводился. Публикации, push, PR и производственного SQL нет.

## Что работает

В действии «Ждать» появились три режима: обычное ожидание, прислушивание, подслушивание. Универсальных категорий по-прежнему шесть. Продолжительность — существующее фиксированное ожидание в мировых секундах, без дополнительного расхода, нового бонуса восприятия, автоматической скрытности или обнаружения. Это заявленное намерение, а не гарантированный результат.

Игрок может выбрать окружение, себя, доступный контакт/объект либо точку XYZ. Сервер использует прежнюю проверку индивидуального раскрытия: координаты требуют открытой схемы и допустимых границ, объекты/контакты — доступной отметки. Сырой скрытый ID существа/объекта нельзя превратить в фокус. Звуковая отметка не идентифицирует существо: для неё остаётся выбор явной точки. Выбор фокуса сам не раскрывает новую сцену, героя или слова.

Намерение хранится как необязательное `wait.listening = {mode,target}`. Старое ожидание и прежние сохранения совместимы. Неизвестные режимы, дополнительный флаг успеха/скрытности и область/направление отвергаются. Копирование отделяет вложенные координаты и оставляет только известные поля. На других категориях `listening` не принимается.

Мастер видит закрытые планы внимания перед расчётом и интервалы заявленного слушания после него. Начало учитывает предыдущие действия в очереди, конец ограничивается границей раунда. Если слушание ещё не началось из-за прежней работы, окно не показывается; если продолжается — отмечается перенос. Режим, фокус и точный остаток сохраняются. Удержанная без продвижения работа не изображается активным слушанием.

Интервалы являются временем заявленного действия, а не выводом о том, что герой физически слышал всё это время. Пограничные события, состояние тела, преграды и скрытность проверяет мастер. Адресная слышимость каждой реплики по-прежнему требует отдельного подтверждения R08. Без решения мастерской системы новые слова не создаются; пассивная слышимость вне указанного интервала не запрещается автоматически. Нельзя получить результат прослушивания только за выбор режима или фокуса.

Другой игрок получает только прежнюю готовность участников, свои заявления и адресные знания; чужое намерение, заметка и фокус не входят в проекцию мира. Говорящий не получает список подслушивающих. При отзыве секретных разрешений панели планов и расчёта удаляются.

## Интерфейс и совместимость

Старый черновик без нового поля режима сохраняет последовательность, текст и незавершённые числа. Частичные XYZ, время и выбранный режим разделены по аккаунту/лобби/герою и переживают переключение вкладок/лобби. Отказ отправки не очищает план. Фокус в собственной отправленной последовательности показывается через доступные герою обозначения.

Новая версия исполнителя — `r08-listening-v1`; неприменённые старые предпросмотры требуют пересчёта. Исполненные `r08-round-speech-v1`, R04 v8/v7 остаются совместимы для переигровки. Отмена работы, снимки, контрольные точки, полные копии и откаты сохраняют/удаляют намерение как часть прежней очереди, без отдельной таблицы или прав. Новых зависимостей/миграций нет.

## Проверки

Добавлены 8 проверок движка, 4 UI и 16 серверных SQLite/PostgreSQL, включая два родительских сценария. Дополнен уже существовавший связный UI/HTTP-сценарий R08: слушатель заранее заявляет подслушивание, мастер задаёт бюджеты и слышимость, видит окно/перенос и применяет раунд. Затем три независимые сессии показывают услышанный фрагмент, отсутствие слов и собственную полную реплику без чужого плана.

Проверяются старые черновики/ожидания, вложенная копия XYZ, строгий режим, точное время, перенос/удержание/очередь, отсутствие автоматических знаний/бонусов, пассивная слышимость по решению мастера, доступные/скрытые цели, приватность, повтор после перезапуска, завершение только остатка и откат/переигровка. JSDOM не заменяет телефон/браузер/WebGL.

Завершены 220 сценариев правил (53 прежних + 167 TAP), 154 UI, 507 серверных и 6 проверок инструмента. Lint — 0 ошибок и 15 прежних предупреждений; TypeScript/сборка прошли, прежнее предупреждение о размере блоков остаётся. Первый `verify:local` отверг незавершённый TAP-вывод правил; повтор той же команды с захватом вывода завершил все 53 + 167 проверки. Исходный отрицательный отчёт сохранён. После уточнения названий объектов по своей сцене повторены 154 UI, lint и сборка. Тест также проверяет одинаковый ID объекта в двух сценах.

Сводный отчёт: `r08-listening-verification-complete-20261012/summary.json`; исходный прогон: `r08-listening-verification-20261012/summary.json`. Сводный файл содержит полные логи и описание повтора, а не объявляет первый запуск успешным. База — `a588067`; реализация проверялась до локального коммита. Далее менялись только отчёт/статус и удалялся шум генерации шести отслеживаемых модулей.

## Голос и следующий этап

[План добровольного голоса](voice-chat-plan.md) подготовлен по первичным WebRTC/MDN-документам и текущему серверному коду. Следующая реализация — общий audio-only голос с добровольным входом, свежими проверками членства, защищённой сигнализацией и закрытием микрофона/соединений при выходе. Малый P2P-прототип не требует нового медиасервера; работа во всех сетях без выбранного TURN не обещается. O12/O13 не объявляются закрытыми. Голосовой чат, микрофон и сторонние службы сейчас не подключены.

Для сохранённых исходников требуется Node 24.x: `npm ci`, затем `npm run verify:local -- --output-dir ../checks-new` с новым каталогом. Перед прямым `npm start` выполнить `npm run server:build`, включая новый общий `roundListening.mjs`; часть общих модулей не хранится в Git. Секреты и рабочие облачные настройки в архив не включены.
