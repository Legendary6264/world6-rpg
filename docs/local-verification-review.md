# Подготовка проверки P23: результат доступной копии

11 октября 2026 года. Подготовлены единый запуск автопроверок, журнал результата и [таблица сквозной приёмки](product-acceptance-plan.md). Это часть подготовки P23; полная приёмка продукта не выполнена.

## Изменения

- `npm run verify:local` запускает шесть наборов последовательно, сохраняет логи и JSON в новый каталог, продолжает после ошибки и возвращает ненулевой код при любом провале.
- Пять проверок инструмента подтверждают, что ошибка отдельного набора не скрывается, следующие команды всё равно выполняются, оба потока вывода попадают в лог, старый отчёт не перезаписывается, отсутствующий инструмент не даёт успеха, а CLI возвращает код `1`.
- План приёмки содержит 21 сценарий с действиями участников, критерием принятия и ограничением текущего состояния. В нём отдельно отмечены отсутствие исходников P11–P21, игровая речь P25 и голос P26.
- Игровой код, правила, канон, ассеты, 3D и облачная конфигурация не изменены. Workflow публикации не изменён.

## Восстановление и границы продолжения

Доступны только P09/P10 и подготовленный P22. Проверка GitHub не нашла коммит P21 `29d6b11`; дополнительные старые ZIP не содержат нужных модулей. Код P11–P21 нельзя признать восстановленным по перечню прежних изменений или сообщениям чата.

Для следующей реализации требуется полный сохранённый патч `grani-bytiya-local-development.patch` либо архив последнего проекта. Подготовленный сейчас Git bundle сохраняет **доступную базу P10, P22 и инструмент проверки**, включая историю Git; отсутствующих этапов в нём нет. После получения полного кода нужно объединить изменения и пройти таблицу приёмки на фактической полной версии.

Изменения локальны: нет push, обновления PR, публикации сайта или записи в производственную базу.
